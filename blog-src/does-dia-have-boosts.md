# Does Dia Have Boosts? What Arc Users Should Know

No, Dia doesn't have Boosts, and Boosts aren't part of Dia's import from Arc. Your bookmarks, passwords, history, extensions and spaces move over; your custom colors, fonts, zaps and CSS don't. Because Dia runs Chrome Web Store extensions, you can get the same thing back with an extension like Pagic, which does per-site colors, fonts, hiding and CSS.

## Why is everyone moving from Arc to Dia?

The Browser Company is shutting Arc down. New accounts are already closed, and the desktop apps stop working on **December 22, 2026**. Dia is their newer browser, built from scratch with AI features, and it's where they're sending Arc users. Dia has picked up a few of Arc's best ideas over time, like a sidebar mode, but Boosts aren't one of them.

## What moves from Arc to Dia, and what doesn't

| From Arc | Moves to Dia? |
|---|---|
| Bookmarks, passwords, history | Yes |
| Extensions | Yes |
| Spaces, folders, tab groups | Yes |
| Boosts (colors, fonts, zaps, code) | No |
| Shared Boosts you installed | No |

So if you open YouTube in Dia, it'll be the YouTube everyone else sees, Shorts and all.

## How do I get Boosts back in Dia?

Dia is built on Chromium, the same engine as Chrome, and installs extensions from the Chrome Web Store. So the answer is an extension that does what Boosts did:

- **Pagic** does all four Boost features except JavaScript: a color pad to tint the page and change its accent, dark mode, any font, click-to-hide (with "Hide all like this" for repeating things like feed posts) and a Code box for your own CSS. Everything is saved per site.
- **Stylus** covers the CSS part, if your Boosts were mostly code.
- **Tampermonkey** covers JavaScript Boosts, if you had any.

I wrote the full migration steps in [the Arc Boosts alternative guide](/blog/arc-boosts-alternative-for-chrome/): list your Boosts, copy the CSS from each one's Code tab while Arc still opens, then rebuild colors, fonts and zaps in a few clicks.

## Do this before December 22

After Arc stops working, you can't open it to look at your Boosts or copy their code. Even if you're not ready to rebuild them, take five minutes now: open each boosted site in Arc, screenshot it, and copy any CSS or JavaScript into a note. Then you can rebuild them whenever you like.

## Is Dia right for you, or something else?

That's a bigger question than Boosts. If you want a browser with Boosts built in, Zen Browser added its own Boosts in 2026 and can import from Arc, but it's built on Firefox. If you're staying on Chromium (Chrome, Dia, Brave, Edge), an extension is how you keep Boosts, and it'll keep working if you switch between those browsers later.

## Frequently asked questions

**Does Dia support Arc Boosts?** No. Dia has no Boosts feature, and its Arc import doesn't include Boosts.
**Can I install Chrome extensions in Dia?** Yes. Dia is built on Chromium and installs extensions from the Chrome Web Store.
**What's the best Boosts replacement for Dia?** For point-and-click colors, fonts, hiding and CSS per site, Pagic. For CSS only, Stylus. For JavaScript, Tampermonkey.
**What happens to my Boosts after December 22, 2026?** Arc stops working, so you can't open it to see or copy them. Copy any CSS or JavaScript from your Boosts before then.
**Which browser has Boosts built in?** Zen Browser, which is based on Firefox, added a Boosts feature in 2026.
