# How to Get Dark Mode in Google Docs and Sheets (Desktop)

To get dark mode in Google Docs on a computer, you need a browser extension, because the page you type on stays white even when Chrome and your system are dark. Google's mobile apps follow your phone's dark mode, but the web version doesn't. Pagic's dark mode handles Docs and Sheets specially: the paper goes dark, the text goes light, and pictures in the document keep their colors.

## Why doesn't Google Docs have dark mode on desktop?

On phones, the Google Docs app follows your system: turn on dark mode and the document goes dark. In a browser, Docs keeps its white page no matter what Chrome or your operating system is set to. The toolbar and menus around it may follow your theme, but the part you stare at for hours doesn't.

## Why most dark mode tools struggle with Google Docs

Here's the technical bit, briefly. A normal website is made of text and boxes, and a dark mode tool can recolor them. Google Docs draws its pages more like pictures, and Google Sheets draws its cells the same way. A dark mode tool that leaves pictures alone leaves the page white. One that darkens everything turns the document into a photo negative, with images inverted too.

Pagic's dark mode treats them as text instead of pictures: the paper goes dark and the words go light, and pictures drawn inside the document flip too so they don't end up as negatives.

## How to get dark mode in Google Docs with Pagic

1. Install Pagic and open a Google Doc.
2. Click Pagic's icon and **Customize this site**. Chrome asks you to allow docs.google.com.
3. Click the **moon**. The page goes dark.
4. Click the moon again for **Auto**, if you want Docs dark only while your system is in dark mode.
5. Drag **Darkness** below 100% if pure black is too harsh. It starts at 95%, a touch softer than black.

Since Pagic saves per site, every Google Doc you open will be dark from now on, and Sheets too (it's the same docs.google.com site).

## Other ways to get a dark Google Docs

- **Chrome's dark mode flag.** In `chrome://flags`, **Auto Dark Mode for Web Contents** darkens every site, Docs included. It's free and built in, but it's for all sites at once and the results vary.
- **Dark Reader.** It darkens Docs too, and many people use it. How well it handles the page depends on its current fixes for Google's layout.
- **A Docs-only extension.** Several extensions on the Chrome Web Store do just this. Fine if Docs is the only site you need.
- **Page color in Docs.** File → Page setup → Page color lets you set a dark page and change the text to white. It works, but it changes the document itself, so everyone you share it with, and every printout, gets the dark version too.

## Does dark mode in Docs change what other people see?

Not with an extension. Pagic and the other tools change how the page looks in your browser only. The document, and everyone else's view of it, stays the same. The one method that does change it for everyone is Docs' own Page color setting.

## Frequently asked questions

**Is there an official Google Docs dark mode on desktop?** Google's mobile apps follow your system's dark mode, but in a desktop browser the page you write on stays white. You need an extension or Chrome's dark mode flag.
**How do I make Google Sheets dark?** The same way as Docs. With Pagic, dark mode on docs.google.com covers both Docs and Sheets.
**Will dark mode mess up the colors in my document?** With Pagic, no. Text colors are adjusted for the dark page, and pictures keep their real colors. Nothing in the document itself changes.
**Can I print a document with dark mode on?** Printing uses the document, not your screen, so it prints in its normal colors.
**Does it work for Google Slides?** Pagic's special handling is for Docs and Sheets. On Slides, regular dark mode applies, so check how your slides look before presenting.
