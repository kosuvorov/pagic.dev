# How to Change the Font on Any Website (Including OpenDyslexic)

To change the font on a website and keep it, use an extension that replaces the site's font with yours, per site. In Pagic, click **Aa**, pick any font installed on your computer (or add one from a file, like OpenDyslexic), and adjust line spacing, letter spacing and text width. Chrome's own font settings only apply to sites that don't set their own font, which is almost none.

## Why Chrome's font settings don't change most websites

Chrome has font settings (Settings → Appearance → Customize fonts), but they're defaults. They apply only when a website doesn't choose its own font, and nearly every website does. Changing them mostly changes nothing.

Zooming (<kbd>⌘</kbd>/<kbd>Ctrl</kbd> and <kbd>+</kbd>) makes text bigger, but also everything else, and doesn't touch the font, the spacing or how wide the lines are.

## How to change a website's font with Pagic

1. Open the site, click Pagic's icon and **Customize this site**.
2. Click **Aa**. You'll see four quick picks (System, Avenir Next, New York, SF Mono) and **•••**, a list of every font installed on your computer, each shown in its own typeface. Type to jump to a font.
3. Pick one. The caption underneath names the font now in use, including the site's own.
4. To go back to the site's font, click the selected font again.

Pagic leaves code and icon fonts alone, so icons don't turn into letters and code stays monospaced.

### Add a font from a file

At the top of the font list, **Add a font from a file…** takes a `.woff2`, `.woff`, `.ttf` or `.otf` file. Once added, it's available on every site you customize. That's how you'd add a font you bought, or one that isn't installed on your system.

## Spacing and line width matter as much as the font

Under the fonts, four sliders change the running text (paragraphs, lists, quotes, headings and articles) while buttons and menus keep their look:

- **Line spacing**, for text that feels cramped.
- **Letter spacing**, which many readers with dyslexia find helpful.
- **Paragraph spacing.**
- **Text width**, for sites whose lines run the full width of a big monitor.

Each slider has a "Site" end that keeps the site's own value. There's also **Case**, which switches all text to lowercase or UPPERCASE, or back to the site's own.

## Using OpenDyslexic on websites

OpenDyslexic is a free font designed with heavier bottoms on letters, meant to make them harder to flip or confuse. Readers' experiences with it vary, and for some, extra letter and line spacing helps as much as the font itself. OpenDyslexic comes with Pagic, so there's nothing to download or install: pick it in the font list, and combine it with wider spacing, a narrower text width and calmer colors from the color pad.

For articles, Pagic's Reader has OpenDyslexic too, along with every font on your computer and themes like Sepia and Night. More in [reader mode in Chrome](/blog/reader-mode-in-chrome/).

## Does a different font stay on every page of the site?

Yes. Pagic saves your choice for the whole site and applies it on every visit. With Pro you can have different looks for different pages of a site, or a separate look for dark mode, as presets.
